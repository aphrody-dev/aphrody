# Code is a Design Material

1. **Interactive Fidelity Over Static Mocks**: Design directly in live, token-driven GPUI/NSH surfaces rather than static slides.
2. **Unified Token Contract**: Every color, radius, typography scale, and motion curve is defined once in `tokens.css` / `google_design_tokens.toml` and consumed by both web/NSH and native GPUI (`os_ui`, `gpui_kit`).
3. **Expressive Motion & Reduced Motion**: State transitions use expressive easing (`cubic-bezier(0.22, 1, 0.36, 1)`) and honor `prefers-reduced-motion: reduce`.
