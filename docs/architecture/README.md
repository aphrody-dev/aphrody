# Aphrody Architecture & Production Documentation

> Canonical, Git-versioned architectural specifications, reproducible automation CLIs, and production readiness plans for the `aphrody` monorepo. Every document and script here resolves exclusively within this repository without external scratch state.

## Architecture Guides

- [Production Readiness & Monorepo Hardening Guide](./production-guide.md): Workspace layering (6 tiers), `Cargo.lock` deduplication, Wasm/WebGPU shrinking & reliability, runtime sandboxing, P0/P1/P2 roadmap, testing pyramid, release packaging, and Cloudflare Workers edge operations.
- [Skills, MCP, ACP, A2A & AI-Ready Ecosystem Plan](./skills-mcp-acp-a2a-plan.md): Unifying `os_craft` MCP, `context_server`, `rmcp 3.10.0`, `brontes 0.7.3`, `agent-client-protocol-rmcp 5.3.0`, `a2a-mcp 0.11.3`, WebMCP, WIT plugins, Tauri v3, and AI-Ready pipelines (`crate-to-skill.ts`, `cli -> mcp`, `cli -> skills`, `app -> plugin`, `pkg -> ai-ready`).
- [Code -> Markdown -> Docs / OpenAPI / `llms.txt` -> Website Plan](./code-to-docs-website-plan.md): Replacing legacy `mdbook` / missing `docs_preprocessor` with `cargo xtask docs` IR extraction, Fumadocs v16 + React Router v7 static prerender, Pagefind/Orama hybrid search, `llms.txt`, `/.well-known/agent-skills/index.json`, and Cloudflare Workers Static Assets ($0 Vercel).
- [Cross-Compilation, LLVM & Hermetic Native SDK (`depot_tools`) Guide](./cross-compile-and-depot-tools.md): `cargo-xwin`, `cargo-zigbuild` glibc pinning, LLVM 23/`lld`/`mold`/ThinLTO/PGO/BOLT, WebRTC & CEF prebuilt caches avoiding 35 GB Chromium checkouts.
- [24/7 Autonomous Dev, Worktree, CI/CD, Channels & Download Architecture](./autonomous-release-ci-cd.md): Out-of-tree isolated worktrees, Merge Queue + GitHub App auto-merge, 6-tier channels (`lts`/`stable`/`preview`/`canary`/`nightly`/`dev`), Sigstore attestations, SHA-256 `auto_update`, and Cloudflare R2 download portal.
- [Monorepo WebAssembly & WebGPU First Architecture](./webgpu-wasm-first.md): Browser WebGPU-first adapter detection, three-cohort `wasm-opt -Oz` pipeline (`baseline`, `simd128`, `--coi`), WASI Preview 2 (`wasmtime 48`), and `wasm-webgpu-first` CI verification.
- [Assembly & WebAssembly Core 2.0 Single-Codebase OS Guide](./asm-and-wasm-core-2-os-guide.md): Unified bare-metal `core::arch::asm!` + W3C Wasm Core 2.0 (`v128` SIMD, bulk memory, sections `0..=12`, LEB128, `.wat`/`.wasm`, WIT Component Model) implemented in [`os_session::wasm_hal`](../../crates/os_session/src/wasm_hal.rs).
- [Awesome GPUI Store & 22-Target Unified Packager](./awesome-gpui-store.md): Live `zed-industries/awesome-gpui` NSH + GPUI cross-platform store (`crates/gpui_store`), `upt 0.9.0` runtime package-manager unification, and 22-target generators (`winget`, `msstore`, `flatpak`, `playstore`, `appstore`, `snap`, `arch`, `nix`, `apk`, `rpm`, `deb`, `xbps`, `gentoo`, `freebsd`, `brew`, `scoop`, `choco`, `appimage`, `oci`, `cargo`, `npm`, `chrome`).
- [Longbridge & Community GPUI Unification & Dependency Graph](./longbridge-gpui-unification.md): Deduplication of 103 `longbridge` repos + community GPUI/Zed into Aphrody, `cargo metadata` feature matrices, dependency centralization, and live showcase sitemaps/screenshots.
- [`wasm-bindgen` Ecosystem, `llms.txt` & Agent Skill](./wasm-bindgen-ecosystem.md) ([`llms.txt`](./wasm-bindgen-llms.txt)): Full GitIngest ingestion across all 8 `wasm-bindgen` org repos, `ExternRef`/zero-copy JS interop, `walrus`/`weedle`/`ts-gen`, and progressive-disclosure skill.
- [`emscripten` Ecosystem, Crawl, `llms.txt` & Agent Skill](./emscripten-ecosystem.md) ([`llms.txt`](./emscripten-llms.txt)): Sphinx site crawl + `xh` route verification + GitIngest across 12 `emscripten-core` repos (`emcc`, `emsdk`, `--use-port=emdawnwebgpu`, Asyncify, SIMD, pthreads, `embind`).
- [Rust Toolchain, Cache, `fmt`/`check`/`clippy` & Cargo Fork Optimization Guide](./rust-toolchain-cargo-optimization.md): Live `sccache`/`lld`/`mold`/`wild`/`cranelift`/`cargo-hakari` audit, Cargo PR cherry-picks (`debug = "line-tables-only"`, `build-dir`, Windows `#3026` `@file` fix), and reproducible fork workflow.
- [GPUI vs Dioxus/Blitz/AnyRender Architecture Graph & Feature Matrix Audit](./gpui-vs-dioxus-audit.md): Live 9-submodule fork graph, 49 Cargo manifests / 444 features, `crates.io` resolution, and shared `WgpuContext` + Taffy bridge verification.
- [`agent-desktop` Purge, Zed/GPUI Migration & Unified AI OS Pilotage](./agent-desktop-ai-os.md): Full 3,801-blob purge accounting (`assets`, `apps/docs`, `probes`, `ffi`, `cursor_overlay`), clean Zed-style [`os_pilot`](../../crates/os_pilot/src/os_pilot.rs) (Windows UIA, Linux AT-SPI2/X11, macOS AX, GPUI AccessKit bridge), unified `os_craft` MCP, and `aphrody-os` AI HUD.
- [CI/CD & Build Host Optimization (`fr1` Ubuntu 26.10 / Kernel 7.3 / XFS / KVM)](./ci-cd-host-optimization.md): Storage tiering (`tmpfs` RAM, local NVMe `sccache`, XFS `reflink` cold snapshots), KVM VirtIO udev queue fixes, Kernel 7.3 `io_uring`/sysctl drop-ins, and `build.slice` runner isolation rooted in Zed's scripts.
- [W3C Internationalization (`w3.org/International/`) Architecture & Implementation](./w3c-internationalization.md): Full W3C CharMod/LTLI/String-Meta/Bidi/CSS Logical/CLDR compliance across [`os_session::i18n`](../../crates/os_session/src/i18n.rs), [`os_ui::i18n`](../../crates/os_ui/src/i18n.rs), [`nsh-i18n`](../../crates/nsh-i18n/src/lib.rs), HTML/SVG surfaces, [`w3c-i18n.ts`](../../tooling/bun/w3c-i18n.ts), and developer workstation UTF-8 config.
- [Aphrody Labs & Ecosystem Deduplication Ledger](./aphrody-labs-deduplication.md): Live 967-repository audit across `aphrody-labs` & `aphrody-dev`, active `.gitmodules` consolidation mapping ([`aphrody_labs_dedup.toml`](../../assets/os/aphrody_labs_dedup.toml)), and verified archive candidates.
