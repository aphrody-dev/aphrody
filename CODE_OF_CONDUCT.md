# Code of Conduct

Contributors and maintainers of **Aphrody (`aphrody-dev/aphrody`)** pledge to keep collaboration welcoming, constructive, and focused on engineering merit for everyone, regardless of background or identity.

- Be respectful in issues, pull requests, and discussions.
- Focus feedback on technical quality, reproducibility, and clear evidence.
- Report unacceptable behavior privately to the repository maintainers via GitHub.
