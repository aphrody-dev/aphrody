# Site: aphrody.com
**Stitch Project ID:** 17049554233938859262

## 1. Vision

Aphrody = [Everything is a file](https://en.wikipedia.org/wiki/Everything_is_a_file) + [Code is a design material](https://design.google/library/code-is-a-design-material). One website that explains Aphrody as one thing: a GPUI operating system and desktop, the Studio IDE, a full-stack framework, one cross-platform binary, and automatic deploy that scales on its own, with Google's design craft throughout.

## 2. Audience

Developers and designers who build native and web apps and want one toolchain from design file to running binary.

## 3. Facts the copy may use (verified in the repos)

- One binary: `aphrody` (crates/zed), Zed-compatible editor and extensions (`.zed/` configs, `zed://` links).
- Platforms with their own crates: Windows, macOS, Linux (Wayland), iOS, Android, web (Wasm + WebGPU), terminal (`nsh-platform-*`, `gpui_*`).
- Framework: GPUI, GPUI Kit (`gpui-kit`), NSH (`nsh-core`, `nsh-base`: shadow tree, layout, navigation, dialogs).
- Design as files: Material 3 tokens in `fw/crates/fw-m3/tokens/google_design_tokens.toml`, `DESIGN.md`, SVG icons generated by scripts.
- Deploy: Cloudflare Workers (`bun run cf:deploy`), web build `bun run web:build:release`; Workers scale automatically.
- Download: https://aphrody.com/download. Source: https://github.com/aphrody-labs/aphrody.
