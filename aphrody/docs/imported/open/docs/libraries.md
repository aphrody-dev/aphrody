# Libraries

Generated by `bun scripts/libraries.ts` from the manifests; the same data is in `libraries.json`. Version 0.4.0.

Rust crates are git dependencies of this repository at a commit; Bun packages are tarballs of the release `libraries-v<version>`, whose internal dependencies point at the same release; the native libraries of the crates with a C ABI are attached to that release for each operating system.

## c-abi (crate)

`crates/c-abi`: Common C ABI primitives of the native libraries: owned JSON strings freed with aphrody_free, framed buffers, borrowed slices, ABI version

```
c-abi = { git = "https://github.com/aphrody-labs/open", rev = "<commit>" }
```

- Rust API: `APHRODY_ABI_VERSION`, `ABI_STATUS_OK`, `ABI_STATUS_ERR`, `ABI_STATUS_INVALID_ARG`, `FRAMED_HEADER_LEN`, `AphrodySlice`, `AphrodyStatus`, `into_c_string`, `json_ok`, `json_err`, `pack_framed`

## ai-router (crate)

`crates/ai-router`: Multi-provider AI router: models discovered at run time (models.dev catalog, local servers), local first then zero-cost then cheapest offers, failover across offers, OpenAI-compatible service, CLI and C ABI

```
ai-router = { git = "https://github.com/aphrody-labs/open", rev = "<commit>" }
```

- Rust API: `capi`, `catalog`, `policy`, `server`, `transport`, `Config`, `Attempt`, `Router`, `Body`, `Forwarded`
- C ABI (crates/ai-router/include/ai_router.h): `aphrody_abi_version`, `aphrody_free`, `aphrody_router_last_error`, `aphrody_router_open`, `aphrody_router_chat`, `aphrody_router_chat_stream`, `aphrody_router_models`, `aphrody_router_close`

## hub (crate)

`crates/hub`: Hugging Face Hub compatible repository service: info, tree, resolve with client headers, content-addressed storage, mirror mode

```
cargo install --git https://github.com/aphrody-labs/open --rev <commit> hub
```

- Rust API: binary
