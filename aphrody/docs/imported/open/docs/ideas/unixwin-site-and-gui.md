# unixwin: the site and the wpm GUI belong to open

Handoff from the src unixwin fusion (docs/native/UNIXWIN.md in aphrody-labs/aphrody). src does not build UI: the two UI surfaces of the unixwin org land here.

## What moves

| Surface | Upstream (pinned in src `src.lock.json`) | What it is | Backend contract it needs |
| --- | --- | --- | --- |
| `unixwin.dev` | `apps/unixwin/upstream/unixwin.dev` (Astro; fork aphrody-labs/unixwin.dev) | product site of niu, rubash, WinuxCmd, oh-my-niu; `/llms.txt`, `/llms-full.txt`, `/agents.md` (build-time Astro routes), per-agent switch pages | the three text endpoints are plain functions (`GET()` returns the text): they render with `bun -e` and no Astro, which is how src captured them into `.agents/skills/unixwin/references/` |
| `wpm-gui` | `apps/unixwin/upstream/wpm-gui` (Svelte; fork aphrody-labs/wpm-gui) | desktop GUI over the WPM package index | now `ay up`: list, install, update (`ay up --list`, `ay up <tool>`), catalog `infra/up/tools.d/wpm.toml` (231 tools, Windows artifacts with sha256) |

## Data contracts available in src

- `ay up --list` and `tools.toml` plus `infra/up/tools.d/*.toml` (generated by `bun scripts/wpm-import.ts --write` from the wpm-source pin): one resolver for wpm and the monorepo tools; `pick."<cmd>@<platform>"` names the archive file.
- `ay applet --list [--json]`: provider of each Unix applet (WinuxCmd base, uutils fills gaps); matrix in docs/native/UNIXWIN.md.
- `ay plugin manifest`: JSON command table, embedded engine, niu and Bun host entries. MCP tools behind the relay hub: `unixwin__unixwin_applets`, `unixwin__unixwin_plugin_manifest`, `unixwin__unixwin_validate_bundle`, `unixwin__unixwin_sh`.
- `bench/shell` result JSON and gap tables (shell performance pages), `test/diffcorpus` results JSON (compatibility page: 306 cases against GNU bash).
- oh-my-niu bundle: `packages/omniu` (`bun packages/omniu/src/cli.ts plugins | validate | package`), for a plugin browser.

## Decisions left to open

UI framework and design system (Material 3 per the open direction), whether the site stays Astro or becomes part of the apps/open web shell, and whether wpm-gui is rewritten on the open desktop stack or kept as a Svelte app. Nothing in src depends on either choice.
